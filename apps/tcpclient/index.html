TCP Client

A simple TCP client for your Mac. Connect to servers and exchange text messages.

About

Connect to any TCP server by address and port, then send and receive text. Handy for testing devices and network services. Pairs well with TCP Server.

Features

  • Connect to any serverEnter host and port and connect.
  • Text messagesSend text and see what the server sends back.
  • Native Mac appSimple, fast and made for macOS.
  • Open sourceSource code on GitHub.
