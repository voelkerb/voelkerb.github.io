TCP Server

A simple TCP server for your Mac. Host servers and exchange text messages.

About

Open a TCP port on your Mac and talk to whatever connects. Handy for developing and debugging devices, sockets and network code. Pairs well with TCP Client.

Features

  • Multiple serversRun several servers side by side, each on its own port.
  • Text messagesReceive text from connected clients and send replies.
  • Native Mac appBuilt for Apple silicon with the latest macOS look.
  • Open sourceSource code on GitHub.
